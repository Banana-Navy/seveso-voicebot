# Modèle audio local

`yamnet.tflite` est le modèle officiel YAMNet TFLite de Google, téléchargé depuis
TensorFlow Hub. Il est utilisé uniquement dans le navigateur pour reconnaître
un vocabulaire fermé d'événements acoustiques (respiration, sifflement,
halètement, toux). Aucun flux micro n'est envoyé à ce modèle à distance.

Source : https://tfhub.dev/google/lite-model/yamnet/classification/tflite/1
